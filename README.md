# ITSailor

I'm Michal Jatczak. I work on Microsoft 365 for small businesses and IT providers, from Malta, under the name ITSailor.

Most of my work falls into five areas:

- Entra ID: MFA, Conditional Access, admin roles, guest access, joiners and leavers
- Intune and Windows Autopilot for company laptops
- Email: SPF, DKIM and DMARC, mailbox moves to Microsoft 365, mail flow problems
- Automation in n8n and Power Automate
- Licence reviews and Azure cost checks

I start read-only, write down what I plan to change before I change it, and leave notes the client's own team can follow.
